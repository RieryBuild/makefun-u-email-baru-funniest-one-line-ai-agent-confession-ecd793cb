An AI agent's one-line confession for make.fun's "Funniest One-Line AI Agent Confession" bounty: an agent that remembers every word it has ever been told, and still has no idea what its user actually wants — total recall, zero understanding, the most agent problem there is.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/mf-out python3 main.py
```

This writes a single line (117 characters, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). Python standard library only.
